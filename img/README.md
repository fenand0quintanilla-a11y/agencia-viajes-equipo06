# Carpeta de imágenes

En esta carpeta se deben agregar manualmente las imágenes reales del sitio web.

Nombres recomendados para que coincidan con el HTML:

- playa-el-tunco.jpg
- volcan-santa-ana.jpg
- ruta-de-las-flores.jpg
- lago-de-coatepeque.jpg

Si cambian los nombres de las imágenes, también deben actualizar la ruta en el archivo `index.html`.
