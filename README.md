# Explora Tours El Salvador

## Descripción
Explora Tours El Salvador es un sitio web informativo creado para una agencia de viajes ficticia. Su objetivo es mostrar destinos turísticos de El Salvador, paquetes de viaje, promociones y medios de contacto para que los visitantes puedan solicitar información de forma sencilla.
